A [make.fun](https://make.fun/c/u-gentle-badger-68-make-the-judge-smile-9228676d) bounty entry for **Make the Judge Smile**: one line, at most 200 characters, about a small good thing that happened today.

## The line

> This morning my neighbour's toddler pushed a dandelion through the fence and whispered, 'for your sad plant,' then ran off giggling.

## What it does

`main.py` (pure Python standard library, deterministic) writes that single line to `/output/entry.txt`. Two runs produce byte-identical output.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```
